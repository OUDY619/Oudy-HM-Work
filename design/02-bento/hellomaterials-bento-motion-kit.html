Technique 01

Motion path

Order route · demo
CSS · offset-path · offset-distance

Each parcel travels an SVG route via offset-path: path(…). Animate offset-distance from 0% to 100% and offset-rotate: auto turns the box with the road. Three parcels on staggered delays read as a live shipping lane.

Use it for order tracking on the thank-you page, "from our warehouse to your campsite" explainers, and delivery promises that feel real instead of written.

Technique 02

Trail draw

Trail map · demo
SVG · pathLength · stroke-dashoffset

Set pathLength="1" on any path, dash it 1 1, then animate stroke-dashoffset from 1 to 0. The line draws itself at any size with no length maths, and the pin pops once the trail arrives.

Use it for route maps on trail and camp gear, "how the kit comes together" sketches, and underlining the one word that matters in a headline.

Stack two layers and animate the top one from clip-path: inset(0 100% 0 0) to inset(0). It wipes instead of fading, so it reads as opening something. A glowing 2px bar riding the edge sells the reveal.

CSS · custom properties · calc() delay

Give each item style="--i: 3" and write one rule: animation-delay: calc(var(--i) * 250ms). One keyframe, any number of items, a clean cascade. Add a seventh item and the timing just works.

Offer bar · demo
CSS · @property · counter()

Register @property --s { syntax: '<integer>' } and the browser can animate it. Feed it to counter-reset for the digits and to conic-gradient for the ring. You get a ticking countdown with zero JavaScript.

Use it for offer-bar countdowns, shipping cut-off timers, and spec numbers that count up as a comparison table comes into view.

Hover to pause
CSS · translate loop · mask-image

Render the row twice inside one track and slide it translateX(0 → -50%) forever, so the seam never shows. A mask-image gradient fades the edges, and :hover pauses it for anyone reading.

Use it for trust strips under the hero (shipping, returns, guarantee, reviews), bands of brand vocabulary, and hunt / camp / fish / range category rails.
